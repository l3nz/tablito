# Whole-row Comparator and Filter, not per-column or chained

A table has at most one Comparator and at most one Filter, each a single function that receives an entire Row and returns an ordering or inclusion decision. This is unlike most table libraries, which typically expose per-column sort comparators and composable/chainable filter predicates. We chose the single whole-row-function shape because it gives every language implementation one function signature to spec and test, instead of a per-column comparator registry plus a separate composition mechanism (AND/OR chains) that would each need their own cross-language vocabulary and test cases. Tablito still ships standard helpers (e.g. build a Comparator from an ordered list of Column+direction pairs) to keep the common case simple; combining multiple filter conditions is left to the caller writing one predicate.
